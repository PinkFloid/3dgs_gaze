# GazeSplat v2 主图：前部与执行照片精修

保留上一版的总体流程、语音绑定分支和用户喜欢的 3DGS 大图。

本次调整：

- 左侧从三块填色流程框改为轻量图标与连续步骤：相机定位、注视提升到三维、注视事件聚类。
- 将平面锥形示意改为佩戴者位姿下的地图渲染及对应局部查询。RGB 上的角范围标记与右侧实例补丁共同说明查询关系。
- 执行照片的裁切窗口由 `(1060, 400, 1700, 1080)` 改为 `(1050, 500, 1480, 1080)`，中心左移并收紧右侧背景。仅裁切和等比缩放，没有修饰照片内容。
- 主 3DGS 图及三个球的实例标签保持上一版原样。

## 素材说明

新增到排版中的 RGB 并非眼动仪实拍图，而是既有真实 3DGS 模型在说明性佩戴者位姿下的渲染；它与 `../fig2_complete/assets/render_metadata.json` 中的说明性查询使用同一原点。查询中心相对目标质心有 8 mm 偏移，RGB 裁切指示标记用于示意角范围，没有声称是实录注视测量。

局部表面图由当前 v2 查询实际计算得到。语音与时间轴仍为方法示意，机器人照片来自既有实录，不宣称为同一轮完整交互。更详细的来源见 `../fig2_complete/README.md`。
