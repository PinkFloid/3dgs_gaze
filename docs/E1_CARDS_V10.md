# v10 补录卡(2026-09-06 建图 lab_colmap_v10;序列事实源 `Eye_Tracker/tools/e1_cards.py`,口播音频 `docs/e1_audio/v1–v6.m4a`)

**通用规则(与 E1_CARDS 相同)**:每项**盯 2–3 秒**,移开看空白处 1–2 秒再看下一项;
开录后先**盯地上的大 tag 3 秒**(2 m/3 m 站位盯脚前的 76 号,4.5/5 m 站位盯前方 2.5–3 m 的 77 或 80 号),
全卡念完再盯同一枚 3 秒,停录。口播音频跟着做即可(它会念"先盯 tag → 1.网球L → 叮=移开 → …")。
**每条录像开录前拉卷尺**:到网球M、到网球L、到网球R 三个距离写进最后的表(正对站位三者应接近下表值)。
录像文件夹名 = 卡号;换人录的加前缀 `p1_`、`p2_`(如 `p1_v1`)。
**东西一毫米都别挪**(地图是静态的);77、80 两张地上的大 tag 先用胶带贴牢。

**v10 摆位**:网球L/M/R 沿桌子长边等距 **24 cm**;"正面" = 站在桌子有大 tag 76 的那一侧(−y 侧),这时 L 在左、R 在右。
第二排的东西正对站会被前排挡住:**苹果粉在网球L 正后方 23 cm,橘子在白杯1 正后方 15 cm**,白杯2 在网球R 后 17 cm——
所以综合卡 V6 要站斜前方(见站位表),纯球卡正对站没问题。

## 录完回来:先算站位与 θ(现场不用看屏幕)

```bash
conda run --no-capture-output -n nerfstudio python Eye_Tracker/tools/station_theta.py --day <日期,如 2026_09_07>
```

目录名里含 v1–v6 就能自动认卡(`p1_v6`、`v1b` 都行;Pupil 自动编号的目录用 `000=v1` 指定)。每条录像给:实际站位
(到 M/L/R 卷尺数、方位角、定位率、看到的 tag)、逐项 θ(**论文口径**=对全部命名物的最小张角,与 eval_e1 的
theta_unit_deg 同源)与落箱;末尾汇总各 θ 箱的缺口,并给下一站建议(球卡 / 综合卡分开)。`--plan` 只看"站位→θ"速查表。

⚠ 论文口径下第二排(苹果粉/橘子/白杯2)就在球正后方 15–23 cm,所以**球卡 3 m 以外 θ 全 <1.5°,4.5/5 m 只有 0.5–0.6°**;
卡片标题里的 6.9°/3.0°/2.75° 是只算三球的数。要补 ≥4° 的箱得站到 1.2–1.5 m(球卡与综合卡都行);1–1.5° 箱 = 3 m。
