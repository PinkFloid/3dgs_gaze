替换 `gaze_object.cone_votes` + `gaze_live.rank_votes` + `attention.accepted` 的 v1 口径。
v1 的形式化描述见会话产出的阅读稿;本文只写 v2 定义、旋钮和与 v1 的差别。

## 定义

一次注视 $F$:均值射线 $\hat{\mathbf r}$(中位样本原点 $\mathbf o$ → 落点均值 $\mathbf c$),距离 $D$。
33×33 patch 张满半角 $h=2\sigma$($\sigma=1.5^\circ$ 固定,bias 关),像素权重
$w_i=\exp(-\theta_i^2/2\sigma^2)$,$W=\sum_i w_i$。

**词表。** `names.json` 减 `places.json` = 目标词表 $T$;场所(物品台、纸箱子)、背景、
无名碎片、无命中、透明、超出深度裕度一律是无效票。KD 树保留全部标注高斯,
无名碎片的表面不再被 5 cm 内的命名邻居认领。

**质量。** $m_k=\sum_{i\to k} w_i\alpha_i$,$q_k=m_k/W$,$p_\varnothing=1-\sum_{k\in T}q_k$。
`vote_share` $=m_k/\sum_{j\in T}m_j$ 保留为目标间相对份额(与 E2 调过的闸门连续)。

**期望捕获。** 目标半径 $r_k$ = 该名字最大实例到质心距离的 84 分位(球 3.1–3.2 cm,杯 4.4–4.8 cm);
$\rho_k=\arctan(r_k/D)$;$c_k$ = 同一像素网格上轴心盘 $\theta_i\le\rho_k$ 内的核质量 $/W$。
$$\mathrm{capture}_k=q_k/c_k\approx e^{-d^2/2\sigma^2},\qquad d=\text{角偏差},$$
与站距、物体大小无关。`miss_deg` $=\sigma\sqrt{-2\ln\min(\mathrm{capture},1)}$。
capture ≥ 1 = 捕获满(渲染的球比均值云大一圈、加 5 cm 认领,完美注视常到 1.2–1.7)。

**后验解释。** 意图先验在 $T$ 上均匀,真视线在目标可见盘面上均匀,噪声各向同性高斯:
$P(k\mid g)\propto \frac{1}{A_k}\int_{D_k}\mathcal N(g;x,\sigma^2)dx$,对比锥小的目标即 capture(差常数)。
无目标 $\varnothing$ 是视野内均匀落点,其常数底折成 capture 阈值。

**排序。** `--rank capture`(v2 默认)按 capture;`--rank mass` 按 $m_k$(v1 的投影面积票,E4 对照)。
无目标质量时 `object=None, object_label=-1`,`surface` 给出无效票中最重的表面名
(场所 / floor / object#id),落点通道用它记「你看的那一点」。

## 闸门(brain,`accepted`)

1. `capture ≥ --min-capture`(0.2 ≈ 偏 1.8σ ≈ 2.7°),v1 事件无此字段则跳过;
2. 票面条件不变:`vote_share ≥ 0.45` 或(≥0.35 且 ≥1.4×第二名);
3. 分段按**歧义比** ambiguity = 第二候选 capture / 第一候选 capture(不是 capture 本身):
   `sure` ≤ `--sure-ratio` 0.25,`unsure` ≤ `--unsure-ratio` 0.5,其余 `ambiguous`,写回事件供绑定策略分段
   (存疑/歧义段交给语音名词类过滤、确认门、dwell;三样 brain 已有,本次未改流程)。
   E4 依据(Eye_Tracker/tools/e4_selective.py):1.0–2.5° 档 v2 判定按歧义比分桶,≤0.25 精度 79%(26 hit/7 extra),
   0.25–0.5 65%,0.5–0.75 44%,>0.75 50%;按 capture 分桶 ≥0.5 的精度只有 56%——密排里赢家离视线都很近,
   错的是选了谁。<1.0° 档 62/72 的判定歧义比 >0.5,精度 ~60% 与桶无关:信息本身不在,只能整体标为歧义。

## 为什么不是全局 $p_\varnothing$ 阈值

完美注视时 $c_k$ 就是能拿到的上限:网球 3 m 只有 0.10、4 m 0.06,$p_\varnothing$ 分别 0.90、0.94;
一个全局阈值留得住远球就拦不住任何东西。capture 把这一项除掉,阈值只剩角度。
真正随距离变差的是邻居角距(4 m 密排球 1.5σ,错判 ~45%),这是分辨率极限,阈值无解,
由下游的名词类过滤和确认门兜底。

## 对象自校准(`--selfcal on`,gaze_selfcal.py)

冻结的 16 条录像里,注视射线相对目标质心方向的系统性偏差**全部向下**:近卡 0.1–0.3°,
3–4.5 m 的卡 1.1–2.1°(逐录像均值是标准误的 5–15 倍),解释了小蓝点常在物体下方与 e2 前排俘获;
随距离增长的部分疑为眼睛与世界相机的视差(标定距离近),该在 Pupil 标定时把标定点摆到工作距离。

自校准把每条无歧义的 final 判定当一次偏置观测(校正后视线 − 目标质心方向,归一化平面,
与 `bias` 同单位),**只改中心,σ 不变**。防「越跑越偏」的护栏(错判当真值是唯一的正反馈通路):

1. capture ≥ 0.3,且第二名候选 capture < 0.05(最近的其他目标离轴 ≥ ~2.4σ);
2. 目标角半径 ≤ σ(大物体看的是哪一点不确定);驻留 ≥ 0.5 s;注视内头部位移 ≤ 0.15 m;
3. 窗口 8 次观测、≥ 3 个不同物体;存的是「隐含真偏置 = 当时用的偏置 + 残差」,更新后旧观测仍有效;
   窗口 MAD > 1.5σ 判不一致不更新(纯噪声约 1.2σ);
4. 每次向窗口中位数走 30%,单步 ≤ 0.5°,总量 ≤ 3°;只往观测拉,不向零衰减。

合成自测(σ 1.5°,真偏置 (0.5°, −1.7°),4 个物体):80 次注视后估计 (0.41°, −1.33°),
误差 0.38°;向零收缩来自观测截断(只收 capture ≥ 0.3 的注视),偏置越修越小截断越轻。
冷启动偏置 ≥ 2σ 时无观测能进门,系统不会更偏但也修不动,需要开场看一个孤立小物体锚定。
未做:tag 被动校验、确认门「好」的强观测、视差项。E4 对照配置 `v2selfcal`。
