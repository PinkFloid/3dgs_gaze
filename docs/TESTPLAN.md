# 测试方案:Intension 指令层 → 全链 demo(2026-07-29)

> 用法:层 0 每次改码必跑;层 1/2 变更交互后过一遍;层 3 上真机前全家族抽测。
> 纪律:**E1 语义用例(A2/B 族)永不改动**;负例必须干净失败(宁可不动);
> 现场踩到新 bug,先补用例进 run_regression.sh 再修(R8/R9 就是这么来的)。

## 0. 四层怎么跑

| 层 | 命令 | 测什么 |
|---|---|---|
| 0 自动回归 | `./Intension/run_regression.sh`(R1-R9,~40s) | 改码后语义没坏 |
| 1 假狗在环 | 终端1 `dog_link.py --fake`;终端2 `brain.py --skill-endpoint tcp://127.0.0.1:5583`;要视线再开 `gaze_live.sh --replay <录像> --publish 5581` | 交互体验/确认门/忙拒 |
| 2 真眼镜干跑 | `gaze_live.sh --publish 5581` + `brain.py`(缺省只打印) | 指代消解不动真狗 |
| 3 真狗 | `brain.py --skill-endpoint tcp://192.168.123.164:5583` | 全链 |

说法一律用当前地图已命名物体(names.json 活文件,以实际为准):
Bottle / orange / apple / cup / 物品台 / 狗桌边 / 黄色机器人 / My Keyboard / 机械臂…
新说法首次过 LLM(~2-5s)后进 parse_cache_v2,demo 台词提前预热一遍。
