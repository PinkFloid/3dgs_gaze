## 2. 每站位流程(≈5 分钟)

1. 开 Pupil recording,文件夹名 `e1_s15 / e1_s30 / e1_s50 / e1_s70 / e1_walk30`;
2. **盯远墙 tag(79 或 86)3 s**(片头戳;别盯 124/126——它们已被排除出戳靶);
3. 按下表逐条:**盯目标球 2–3 s → 移开看空白墙面/空地 1–2 s**(让聚类关簇);
4. 全序列完 → **再盯同一枚墙 tag 3 s**(片尾戳)→ 停录;
5. 换站位后重复。摘过眼镜必须重标定。

在线跑 gaze_live 时:`--stamp-exclude 126,124`(124 在台前脸,远站位与球夹角进 4° 门)。

## 4. 事后打分(离线,不占场地时间)

1. `gaze_live.py --replay <rec> --headless --log intents.jsonl --stamp-exclude 126,124`;
2. 逐 trial 对齐:第 k 个非背景 final 注视 ↔ 卡上第 k 条(全程按卡盯,不额外看物体);
3. 判对 = verdict 名字与卡一致;逐 trial 记 位姿距离、角间隔、vote_share、p_none、σ(t);
4. 汇总:按角间隔分箱 → Fig.4;名义距离列用于核对站位没站错。
