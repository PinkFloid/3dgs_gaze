## 1. 实验章需要的"步骤"(每一段该写什么,一段一件事)

**A. Setup(半栏)**:硬件(Pupil Core、B2 + 臂、iPhone 建图、4090);地图 4 张(v7/v8/v9/v10,同一房间四次独立布置建图,
每张 SAM 实例数与命名数);标定(每次佩戴重标,σ_cal 0.8–1.1°);参与者 3 人(作者 + 2,披露比例);
θ 的定义(**目标到任一其他命名物的最小张角,由站位头位中位算,与结果无关**);计分规则一句(冻结:顺序 + 时段内最长注视;
gap<1.2 s 合并、段 ≥1 s;背景/地面丢弃)。**所有处置只在这里说一次**(Data hygiene 段)。

**B. E1 = 视线→实例(离线回放,不用狗)**:16 张预注册卡、14+12 个站位、1.0–4.6 m;每项盯 2–3 s。
输出一张图(Fig. 4)+ 三个数:≥2.5° / 1–2.5° / <1°(清晰 vs 遮挡)。边走单列一句(56/57)。

**C. E2 = 端到端取物(真狗)**:用户盯 + 说,系统解析→绑定→派单→狗导航→最后一米重投影→抓→递。
成功判据:零干预到达正确实例并完成后续动作。K = 39(20 有日志 + 19 现场判),按指代方式分两行,失败按七分类,时延一句。

**D. E3 = 视野内/外等价(真狗)**:同一目标两臂各一次,狗在房内看得见 vs 在门外看不见。8 对,7/8 vs 7/8。
这是 C1 的直接证据:指代不依赖机器人相机看见目标。

**E. E4 = 回放消融**:同一批录像逐 trial 回放,只换一个机制。表的每一行 = 一个机制 vs 它替换的朴素做法(§3)。

**F. System characterization(一句一个)**:定位覆盖率、戳后 σ、单次深度/锥查询耗时、派单回执、急停时延。
