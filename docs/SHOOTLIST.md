# 拍摄与数据采集清单(2026-07-29 定稿)

> 方针(用户拍板):**除视频 5 正片必须真拍外,其余先不拍视频、走 replay**——
> 眼动仪 recording 就是数据本体,录一次可离线反复出结果(process_recording +
> `brain --replay` + `--script` 注入指令,与回归同一机制)。
> **语音暂缓接入**;死线 = 正片排练日(正片硬约束"手不入画",到时必须语音)。

---

**视频 1|地图质检** —— 重建完当天做,只需眼动仪录制,不用外部机位
- 摆:桌上 5 个网球一排 + 苹果、香蕉、橘子。
- 做:标定 → 开录 → 盯墙 tag 3s → 按固定顺序每球盯 2-3s、每水果盯 2-3s、
  中间偶尔扫 tag → 结尾再盯 tag 3s → 停。全程 2-3 分钟。
- 结果:离线出 overlay 视频,看**每次盯的物体框和名字对不对**。全对=地图能用;
  这段录像同时是论文注视叠加截图 + 回放调参素材,一鱼三吃。

**视频 2|选球准确率数据** —— 眼动仪录制即可,指令用 replay 注入,暂不配语音
- 摆:桌不动,**你换站位** 1.5 / 3 / 5 / 7 m,卷尺量好记下。
- 做:每组重查标定;按纸上预写的顺序(球2、球1、球3…)逐条**盯目标球 2-3s**,
  每组 15-20 条,一条不删。指令("把这个网球拿来")事后用 `--script` 在对应时刻
  注入回放,系统选哪只自动进日志。
- 结果:拼出"**站得越远、还能不能选对**"的曲线——论文最硬的一张图。
- 外部机位交代镜头(你站哪、卷尺入镜)推迟到正式采集日补拍。

**视频 3|取物全流程** —— 等真狗排期,与 trial 一起拍
- 摆:狗趴门外(看不见桌子);手机三脚架,一个画面框住**门口+你+桌子**,别动机位。
- 做:每轮从说指令录到送达/失败。桌边可加一路抓取近景。
- 结果:每轮成败的裁判证据(拿的对不对、有没有人帮忙、失败归哪类)。

**视频 4|"狗看不见目标"证据** —— 30 秒,和视频 3 同天顺手拍
- 手机放狗门外趴位、狗头高度:一张照 + 环视 10s,画面里只有墙和门、看不到桌子。
- 结果:论文一张图,证明狗接指令时是"瞎"的,全靠地图。

**视频 5|正片(唯一必须真拍)** —— 一条过、无剪辑,投稿演示视频
- 摆:同视频 3,加两路:眼动仪画面(带注视光标)画中画 + 电脑录屏;开拍拍手对齐。
- 做:排练到熟后一条过:**全程手不入画** → 盯三只同款网球中的一只 →
  说"把这个网球拿来" → 狗进门、**抓起正是那只**、送到你面前。
- ⚠ 排练日前必须就位的两件事:①语音接入(faster-whisper);
  ②狗端"就近匹配"(object_hint,不然同款球末端可能拿错只)。

**视频 6|零碎素材** —— 手机随手,重建当天顺手拍最省
- 场景全景、门宽/桌位/站位卷尺测量照、tag 位置、网球特写(证明无任何标记)。
- 结果:画场地平面图、写实验设置用。
